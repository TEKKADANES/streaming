Aula Streaming · Herramienta 03

Editor de listas M3U

Edita canales, busca y asigna logos, organiza categorías y exporta tu lista personalizada. Los archivos se procesan en el navegador.

Lista de canales

Carga una lista local .m3u o .m3u8. Puedes asignar logos del catálogo, usar una URL externa o subir una imagen a ImgBB.

Sobre ImgBB: crea una cuenta en imgbb.com y obtén una API key desde su página de API. Solo al pegarla y pulsar “Subir a ImgBB” se enviará la imagen; ese servicio la alojará públicamente. Sin API key, el logo se conserva localmente y la exportación M3U lo embebe como data URI, que puede ser largo.

Elige una lista local para comenzar.

Categorías y filtros

Agrega categorías y filtra los canales para organizar la lista.

Añadir canal

Añade una entrada nueva directamente a la lista que vas a exportar.

Gestiona solamente canales y recursos propios o con autorización. La herramienta no aloja ni retransmite medios.
