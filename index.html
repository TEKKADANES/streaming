    Probador de listas M3U/M3U8

    Lee una lista local y revisa los nombres y enlaces que contiene. La página no intenta reproducir ni retransmitir los medios.

      Editar lista

      Importa una lista local M3U/M3U8, corrige nombres, asigna logos y categorías, y descarga el resultado ordenado por categoría. La búsqueda de logos usa el catálogo público de tv-logo/tv-logos/countries.

      Privacidad: las listas y logos que subas se procesan en esta página; no se envían automáticamente a ningún servidor. No se puede publicar de forma segura en un repositorio privado directamente desde HTML: para ello se requiere un servicio de servidor autenticado. Nunca incluyas un token de GitHub en esta página.

      Elige un archivo para empezar.

      La coincidencia automática compara el nombre del canal con los nombres de archivo del catálogo y solo propone resultados; confirma cada logo. Si el canal no aparece, puedes cargar una imagen local en su fila. Los logos locales se incluyen en el M3U exportado como datos embebidos.

      Acortador de enlaces

      La URL se envía al servicio externo is.gd. No introduzcas enlaces privados.

      Usa únicamente recursos propios o con autorización. Esta herramienta educativa no aloja, distribuye ni retransmite canales.
