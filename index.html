    Probador de listas M3U/M3U8

    Elige una lista local o indica una URL remota. Se comprueba cada enlace cuando es posible; las restricciones CORS y de red se indican como no verificables, no como enlaces caídos.

    Formatos: admite URLs directas de video (MP4, MKV, MOV, WebM, AVI) y audio (MP3, WAV, M4A, AAC, OGG, FLAC). 404/410 se consideran no disponibles. Una respuesta positiva confirma que el servidor respondió, no la compatibilidad con todos los reproductores.

    El archivo local no se sube; la URL remota se descarga al navegador y puede requerir CORS.
