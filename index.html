Creador de listas M3U

Añade URLs directas de video, audio u otros medios. Esta herramienta organiza los enlaces; no descarga ni convierte archivos.

    Probador de listas M3U/M3U8

    Elige una lista local o indica la URL remota del archivo de lista. Luego comprueba los enlaces de medios que contiene.

    Formatos: admite URLs directas de video como MP4, MKV, MOV, WebM, AVI y audio como MP3, WAV, M4A, AAC, OGG y FLAC. La lista se lee localmente si se carga desde tu dispositivo. Para listas remotas, el servidor debe permitir CORS. Los enlaces de medios también pueden ser no verificables si CORS o la red bloquean la comprobación; se identifican aparte y no se marcan falsamente como caídos. HTTP 404/410 se marca como no disponible. Una respuesta positiva confirma que el servidor contestó, no que todos los reproductores soporten el formato.

    El archivo local no se sube; la URL remota se descarga al navegador.
